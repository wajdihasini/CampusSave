# Plan du Rapport Pédagogique — CampusSave (ESSECT)

1. **Introduction & Problématique** : Lutte contre le gaspillage alimentaire autour de l'ESSECT Montfleury.
2. **Analyse des besoins & Acteurs** : Étudiant, Commerçant, Administrateur (cas d'utilisation UML).
3. **Architecture Technique** : Client Web React, Client Mobile Flutter, API REST Express.js, Firebase (Auth, Firestore, FCM, Admin SDK), Konnect Sandbox.
4. **Conception de la Base de Données & Sécurité** : Modèle Firestore, règles de sécurité `firestore.rules`, protection des stocks par transactions, QR Code signé à usage unique.
5. **Réalisation & Interfaces** : Captures Web et Android, scénarios de test complets.
6. **Conclusion & Perspectives** : Bonus envisageables (Campus Radar, EcoPoints, Impact Dashboard).
